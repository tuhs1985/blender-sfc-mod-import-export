# Design

Add choices to the existing export options dialog for standard and break outputs: current export (default), Blender smoothing, and split by angle. For Blender smoothing, evaluate each mesh and split manifold edges marked sharp or whose evaluated corner normal directions differ across the edge. This captures flat/smooth and sharp boundaries without assuming direct per-corner normal support in OP. Alternatively split manifold edges with face angles above the selected threshold. Work on a temporary BMesh; preserve UVs, materials, transforms, LOD ordering and break IDs. Leave the original mesh and modifiers unchanged and free temporary data. Disabled exports retain existing code paths and raw records. Recalculate normals as existing edited geometry does: exact custom normal directions are not preserved. Do not impose mesh-quality restrictions. Blender background tests cover shading boundaries, angled shared faces, disabled behavior, source preservation, UVs and break export; user may check results in MOD Viewer.
